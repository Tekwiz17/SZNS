This release fixes animations freezing in the menu bar, Dock, desktop effects and settings previews.

The drawing views now use each SwiftUI timeline frame to update their contents. A new release check compares actual window screenshots over time to catch this regression.

SZNS continues to honor macOS Reduce Motion. General → Accessibility now explains when that setting makes decorations still.

Download **SZNS-macOS.zip**, quit the previous SZNS, unzip the download, and replace **SZNS.app** in Applications. The universal app supports Intel and Apple silicon on macOS 14 or newer. See [Opening a downloaded app](https://github.com/Tekwiz17/SZNS#opening-a-downloaded-app) for the locally signed download.
